# JEMBATAN $59.000 — 21 November's world news in one image

One image summing up 21 November 2026: **Bitcoin crashed to $59,000**.

A cracked golden Bitcoin coin lies across a wide river as a stepping
stone. People walk over it toward a bright green, sunny shore on the
other side. The coin is cracked — the price fell hard — but it is still
strong enough to cross on.

Headline on the image: **JEMBATAN $59.000**
Caption: **Retak tapi tetap bisa diseberangi** (cracked, but still
crossable).

## Files

- `entry.jpg` — the image (1024×1024).
- `main.py` — the reproducible build step: copies `entry.jpg`
  byte-for-byte to `$MAKEFUN_OUTPUT_DIR/entry.png` (default
  `/output/entry.png`). Standard library only, no network, no
  third-party packages.

## Run locally

```sh
python3 main.py
```
